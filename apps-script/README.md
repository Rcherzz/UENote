# Apps Script Deployment

Copy these files into a Google Apps Script project bound to the target Google Sheet:

- `Code.gs`
- `Index.html`
- `Style.html`
- `App.html`

Deploy as a Web App:

- Execute as: `User accessing the web app`
- Who has access: `Anyone with a Google account`
